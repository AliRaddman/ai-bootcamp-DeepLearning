# مسئله اول: تشخیص تصادف

هدف این بخش، طراحی یک سیستم دسته‌بندی دودویی است که با دریافت یک ویدئو تشخیص دهد آیا در آن تصادف رخ داده است یا خیر.

داده‌های این بخش شامل ویدئوهای کوتاه و متادیتای مربوط به آن‌ها است.

برچسب هر ویدئو بر اساس ستون `time_of_event` تعیین می‌شود:

- وجود مقدار در `time_of_event`: وقوع تصادف
- مقدار خالی یا `NaN`: عدم وقوع تصادف

از آنجا که ورودی‌ها ویدئویی هستند، ابتدا تعدادی فریم با فاصله زمانی مشخص از هر ویدئو استخراج می‌شود. سپس مدل‌های تصویری و زمانی روی این فریم‌ها آموزش داده می‌شوند.

## Notebookهای بخش CV

|---|---|---|---|
| 1 | `01_cv_data_preparation.ipynb` | مهیا | بررسی دیتاست، ساخت برچسب‌ها و تقسیم Train/Validation |

# مسئله دوم: تحلیل احساس نظرات

هدف این بخش، بررسی نظرات ثبت‌شده برای محصولات الکترونیکی آمازون و طراحی مدلی برای پیش‌بینی امتیاز هر نظر از ۱ تا ۵ است.

متغیر هدف، ستون `overall` و ورودی اصلی مدل، ستون `reviewText` است.

این بخش شامل موارد زیر است:

- تحلیل اولیه داده‌ها
- بررسی توزیع امتیازها
- رسم Word Cloud
- تحلیل طول نظرات
- بررسی محصولات و برندها
- تحلیل نظرات مرتبط با گارانتی
- ساخت مدل پایه تحلیل احساس
- آموزش مدل عمیق
- پیش‌بینی داده‌های آزمون
