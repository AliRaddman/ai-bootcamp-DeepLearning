# پروژه دوم بوت‌کمپ هوش مصنوعی کوئرا

این مخزن مربوط به پروژه دوم بوت‌کمپ هوش مصنوعی کوئرا در بهار ۱۴۰۵ است.

پروژه شامل دو مسئله اصلی است:

1. تشخیص وقوع تصادف از روی ویدئو با استفاده از بینایی ماشین
2. تحلیل احساس نظرات محصولات آمازون با استفاده از پردازش زبان طبیعی

روند اجرای پروژه به این صورت است که ابتدا بخش بینایی ماشین تکمیل می‌شود و سپس تیم وارد بخش پردازش زبان طبیعی خواهد شد.

| بازه زمانی | فاز |
