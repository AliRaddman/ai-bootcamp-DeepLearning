## ابزارهای مورد استفاده

### GitHub

GitHub برای موارد زیر استفاده می‌شود:

- نگهداری Notebookها
- نگهداری READMEها و مستندات
- ثبت تاریخچه تغییرات
- بررسی مشارکت اعضای تیم
- نگهداری نسخه نهایی پروژه

### Google Colab

Google Colab محیط اصلی اجرای کدهای پروژه است و برای موارد زیر استفاده می‌شود:

- اجرای Notebookها
- استفاده از GPU
- پردازش ویدئوها و داده‌های حجیم
- آموزش مدل‌های بینایی ماشین
- آموزش مدل‌های پردازش زبان طبیعی
- اجرای نسخه نهایی Notebookها

### Google Drive

Google Drive برای نگهداری فایل‌های حجیمی استفاده می‌شود که نباید در GitHub قرار بگیرند:

- داده‌های خام
- ویدئوها
- مدل‌های آموزش‌دیده
- Checkpointها
- Predictionها
- فایل‌های خروجی مشترک

ساختار پیشنهادی پوشه مشترک Drive:

```text

├── data/
│   ├── cv/
│   └── nlp/

│   ├── cv/
│   └── nlp/

    ├── cv/
    └── nlp/
```

## روش اجرای Notebookها

Notebookها در GitHub نگهداری می‌شوند و برای اجرا در Google Colab باز خواهند شد.

در ابتدای Notebookهایی که به فایل‌های Drive نیاز دارند، Google Drive متصل می‌شود:

```python
from google.colab import drive

drive.mount("/content/drive")
```

مسیر اصلی پوشه مشترک پروژه:

```python
PROJECT_ROOT = "/content/drive/MyDrive/AI_Project2"
```

در صورتی که پوشه مشترک در بخش دیگری از Drive قرار داشته باشد، مسیر باید متناسب با محل واقعی آن تغییر داده شود.

## روش همکاری تیم

- Notebookها و مستندات در GitHub نگهداری می‌شوند.

- جزئیات تقسیم وظایف در README مربوط به هر بخش قرار دارد.
- مسیرهای Drive باید در ابتدای Notebookها مشخص و قابل تغییر باشند.
- خروجی‌های مورد نیاز اعضای بعدی باید در پوشه مشترک Drive ذخیره شوند.
