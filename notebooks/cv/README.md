# مسئله اول: تشخیص تصادف

هدف این بخش، طراحی یک سیستم دسته‌بندی دودویی است که با دریافت یک ویدئو تشخیص دهد آیا در آن تصادف رخ داده است یا خیر.

داده‌های این بخش شامل ویدئوهای کوتاه و متادیتای مربوط به آن‌ها است.

برچسب هر ویدئو بر اساس ستون `time_of_event` تعیین می‌شود:

- وجود مقدار در `time_of_event`: وقوع تصادف
- مقدار خالی یا `NaN`: عدم وقوع تصادف

از آنجا که ورودی‌ها ویدئویی هستند، ابتدا تعدادی فریم با فاصله زمانی مشخص از هر ویدئو استخراج می‌شود. سپس مدل‌های تصویری و زمانی روی این فریم‌ها آموزش داده می‌شوند.
